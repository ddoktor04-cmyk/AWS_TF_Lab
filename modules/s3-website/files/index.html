⚠ Fallback

Резервна сторінка (SECONDARY)

Route53 DNS failover визначив, що PRIMARY endpoint недоступний, і скерував вас на статичний сайт у S3 (eu-west-1).

  • Primary: ALB + EC2 у eu-central-1 — недоступний
  • Secondary: S3 website — активний
  • Моніторинг: Route53 HTTP health check (30s, 3 failures)
source: Amazon S3 static website (eu-west-1)
